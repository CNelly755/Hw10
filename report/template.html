Maybe he meant something else by “less snow”

“Less snow” can mean less snow falling, fewer snowy days, or less time with snow on the ground. Those can move differently: a warmer winter can bring the same total snowfall but melt it faster. So I tested all three, using the same stations-and-seasons rules.

How I did it

  1. Data. Daily snowfall (SNOW) and snow depth (SNWD) from NOAA's Global Historical Climatology Network – Daily (GHCN-Daily), downloaded {{RUN_DATE}}. Values that failed NOAA's quality checks were dropped.
  2. Stations. Every station in Connecticut, Massachusetts, Maine, New Hampshire, Rhode Island and Vermont whose snowfall record begins by 1945 and runs to at least 2020 ({{N_CANDIDATES}} candidates). A station was kept for a measure only if at least 75% of its winters in each period were complete, which left {{N_STATIONS}} stations for snowfall.
  3. Winters. A winter runs July 1 to June 30 and is named for the year of its January, so “2001” is the 2000–01 winter. A winter counts only if November through March each have at least 25 days of valid observations.
  4. Measures. Total seasonal snowfall; days with 1″ or more of new snow; and days from November to March with at least 1″ of snow on the ground (scaled up for the few missing days).
  5. Regional index. Snowy hill towns and the coast get very different amounts, so each station's winter is expressed as a percent above or below that station's 1941–2000 average, then averaged across stations. That keeps a handful of snowy stations from dominating, and stops the result from shifting just because a station is missing a winter. For readability the index is also shown in inches for a “typical” station (the average station's 1941–2000 normal of {{TYPICAL_NORMAL}} inches).
  6. Tests. The headline rule was set before running the analysis: Yes if the {{RECENT}} regional average is lower than the {{BASELINE}} average and a one-sided permutation test (20,000 random reshufflings of winters between the two periods) gives p < 0.05; otherwise No. I also report a bootstrap 95% confidence interval, a Mann–Whitney test, per-station Welch t-tests, and a sign test on how many stations went down.

Caveats

  • Snowfall is a hard thing to measure. It depends on how often the observer clears the board, wind, and whether the gauge moved. Most of these stations are volunteer cooperative observers, and station moves are not corrected for in the raw daily data.
  • Stations are not independent. Neighboring stations see the same storms, so the station counts overstate how much independent evidence there is. The headline test therefore uses the regional series, where each winter is one data point.
  • Twenty winters is a short window. New England snowfall swings a lot from year to year (a single big nor'easter can make a season), so modest real changes can be hard to separate from noise.
  • Memory is not a rain gauge. Snow looks deeper when you are small, and the winters people remember best are the extreme ones. The data can say what happened on average, not what a person experienced at any one place.

Reproduce it

All code is in the GitHub repository. With Python 3.10+:

pip install -r requirements.txt
python run_all.py

This downloads about {{N_CANDIDATES}} station files from NOAA, runs the analysis, and writes this page to site/. The repository's GitHub Actions workflow does the same thing on every push and publishes the result here.
