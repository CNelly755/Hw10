# Hw10
# Was my uncle right about the snow?



My uncle (1939–2024) lived most of his life in New England and often said there was less snow
nowadays than there used to be. This project tests that claim with NOAA's
[Global Historical Climatology Network – Daily](https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily)
(GHCN-Daily). It compares the winters of **2001–2020** (the first two decades of the 21st century) with the
winters of **1941–2000** (the last six decades of the 20th century) at long-running weather stations in
Connecticut, Massachusetts, Maine, New Hampshire, Rhode Island and Vermont.

The report linked above gives the headline answer (**Yes** or **No**), the evidence, charts, a station-by-station
breakdown, checks of the answer under other framings, and caveats.

## How the answer is decided

The rule was fixed before the analysis ran (see `scripts/common.py`):

> **Yes** if the 2001–2020 regional average seasonal snowfall is lower than the 1941–2000 average **and** a
> one-sided permutation test gives p < 0.05. Otherwise **No**.

"Regional average" means each station's winter is expressed as a percent above or below that station's own
1941–2000 average, and those percentages are averaged across stations. That way snowy mountain stations and
coastal stations count equally. The report also tests two other things "less snow" could mean: days with 1 inch
or more of new snow, and days with 1 inch or more of snow on the ground.

## Run it yourself

Requires Python 3.10+.

```bash
pip install -r requirements.txt
python run_all.py
```

Then open `site/index.html`. The pipeline has three steps, which can also be run one at a time:

| Script | What it does |
|---|---|
| `scripts/download_data.py` | Downloads NOAA's station list and inventory, picks New England stations with snowfall records from 1945 or earlier through 2020 or later, and downloads each station's daily record into `data/raw/`. Cached files are reused; `--refresh` re-downloads. |
| `scripts/analyze.py` | Computes per-station, per-winter snowfall, snowy days and snow-cover days; applies the completeness rules; builds the regional index; runs the statistical tests; and writes tables to `output/` and charts to `output/figures/`. |
| `scripts/build_report.py` | Fills `report/template.html` with the results and writes the website to `site/`. |

`scripts/common.py` holds every setting (periods, states, completeness thresholds, the headline rule) and the
parsers for NOAA's fixed-width file formats.

### Testing without the network

`tests/make_synthetic_data.py` writes fake station files in NOAA's exact format so the pipeline can be checked
offline, e.g. `python tests/make_synthetic_data.py --trend -0.25 && python run_all.py`. Delete `data/` (or run
`python run_all.py --refresh`) before producing the real report.

## Publishing

The report is built and deployed by GitHub Actions (`.github/workflows/pages.yml`) on every push to `main`: it
downloads the data from NOAA, runs the analysis, and publishes `site/` to GitHub Pages. To turn it on, go to
**Settings → Pages** in the repository and set **Source** to **GitHub Actions**.

## What is not in this repository

Raw NOAA data (`data/`), analysis output (`output/`) and the built site (`site/`) are all generated by the scripts
and excluded by `.gitignore`. They have never been committed.
